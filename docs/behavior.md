# 能力、风格和战法

## 五档能力

| 能力 | 每节点候选 | 阶段跨度 | 协作 | 预案 | 敌方反应风险项 |
| ---- | ---------: | -------: | ---: | ---: | -------------: |
| 新手 |          2 |        1 |    0 |    0 |              0 |
| 普通 |          3 |        2 |    1 |    0 |              0 |
| 熟练 |          4 |        3 |    2 |    1 |              0 |
| 优秀 |          6 |        4 |    3 |    2 |              1 |
| 大师 |          8 |        6 |    4 |    3 |              3 |

新手侧重眼前目标和威胁；普通增加角色；熟练增加地形与阶段收益；优秀考虑预备队与可见反击风险；大师进一步考虑多分队集中及多种响应风险。风险近似来自已知火力、包围和资源情况，不预测不可见敌军。

这些参数可以用 `profiles` 覆盖，也可新增能力 ID。单位 HP、伤害和地图观察不因能力等级变化。高档不是必胜保证，首版没有宣称在所有场景具有单调胜率。

## 十种战法

| 战法           | 默认执行倾向                           |
| -------------- | -------------------------------------- |
| 中央突破       | 集中推进、正面攻击、扩大突破成果       |
| 侧翼突破       | 绕行侧翼、机动接近、保持支援           |
| 包抄           | 两翼展开、正面牵制、同步收拢           |
| 火力准备后突击 | 支援单位先行发挥火力，随后增加突击收益 |
| 固守           | 维持目标阵地、火力与防御动作           |
| 弹性防御       | 降低暴露、换位、利用纵深               |
| 机动防御       | 机动集中、局部反击                     |
| 逐线迟滞       | 安全换位、短促交火和掩护               |
| 佯攻牵制       | 侧向活动、有限接触、保全兵力           |
| 交替掩护撤退   | 朝撤离目标移动，保留掩护角色           |

它们都是宿主合法动作上的任务模板和评分规则。阶段保存进入／完成／中止条件，未来动作不会硬编码为固定坐标序列。具体效果取决于宿主是否提供移动、攻击、压制、侦察等动作和准确的特征。

局部伤亡、通路阻塞触发受影响指挥官任务修复；目标更新触发相关计划重建；用户锁定的任务保留。受损兵力的基线被记录，同一伤亡不会每轮重复触发改案。没有存活单位的任务结束，不无限重建。

## 十四维风格

全部使用 0–100 整数，50 时风格贡献为零。

| 维度           | 候选中的影响项                     |
| -------------- | ---------------------------------- |
| 侧翼倾向       | 侧翼路线、绕行位置                 |
| 火力倾向       | 远程火力动作                       |
| 预备队投入倾向 | 预备队数量、投入阈值与当前兵力投入 |
| 任务专注       | 目标推进与任务连续性               |
| 集中倾向       | 关键目标的兵力／火力集中           |
| 坚守倾向       | 保持阵地与让出位置                 |
| 佯攻倾向       | 牵制动作特征                       |
| 进取倾向       | 推进和主动交战                     |
| 风险容忍       | 接受可见风险                       |
| 兵力保全       | 安全位置与低损失动作               |
| 机动倾向       | 转移和换位                         |
| 侦察倾向       | 宿主提供的侦察动作                 |
| 耐心倾向       | 等待与同步                         |
| 自主倾向       | 在授权范围内调整方法               |

界面根据注册项生成滑块，评分表分开显示收益、风险、风格和总分。不能用风格绕过合法性、单位归属或玩家锁定。

新增特征必须由宿主或公开评价模块提供明确含义。若某场景没有对应动作，调高该风格不应凭空产生新能力。例如完全可见的演示战场里，侦察动作并不凭空发现额外敌人。
