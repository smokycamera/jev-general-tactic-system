# 战术、能力与风格

战术目录分五类，共 32 个可扩展模板。目录层级用于组织与筛选，不会逐层调用模型。左右侧翼作为参数；火力准备、佯攻等作为可组合的辅助战法。

| 类别           | 内置方案                                                                                                   |
| -------------- | ---------------------------------------------------------------------------------------------------------- |
| 进攻           | 正面攻击、中央突破、局部重点突破、侧翼攻击、单翼包围、双翼包围、渗透、迂回、突袭、火力准备后突击、佯攻牵制 |
| 防御           | 固守、纵深防御、弹性防御、机动防御、据点防御、伏击防御                                                     |
| 退却作战       | 逐线迟滞、战斗迟滞、战斗撤退、交替掩护撤退、脱离接触、突围                                                 |
| 侦察与警戒     | 侦察、试探、强行侦察、警戒、掩护                                                                           |
| 反击与战果利用 | 反击、反攻、突破扩张、追击                                                                                 |

辅助战法有 10 种：火力准备、火力压制、佯攻、牵制、集中兵力、分散展开、预备队投入、烟幕与遮蔽、协同突击、次要方向节约兵力。它们通过增补或调整执行任务组合，而不增加一串模型请求。原有 `fire-then-assault` 和 `feint-fix` ID 保留为完整配方，便于已有配置继续使用。

侧翼参数 `direction` 支持 `auto`、`left`、`right`；方向相对于己方接近目标的方向计算。局部重点突破可使用 `sector` 指定候选区域 ID。其他参数是开放 JSON 字段，由自定义战法解释。

## 计划如何执行

- 火力准备后突击：支援单位实际完成攻击后，才解锁后续接近和突击。仅经过几个回合不会完成火力准备。
- 单／双翼包围：牵制组与机动组有不同单位和任务；所有必要前置任务完成后才解锁突击。受阻机动分支可更换可达集结点，保留已完成的牵制任务。
- 交替掩护撤退：首组准备掩护，另一组先转移；另一组抵达并完成掩护准备后，首组才撤出。
- 预备队投入：预备队从主攻任务中分离，在配置的延迟或不利态势条件满足后参与战斗。
- 有意坚守、等待接触不会被通用无进展计时器误判；移动等任务在无进展时有限重试，失败后更换方案。

这些是规则模板。默认牵制以实际攻击、掩护准备以攻击或防御回执为依据；不会凭空给敌人添加压制、恐惧或被牵制状态。若游戏提供更精确的压制、士气、面向或持续掩护规则，应注册对应操作与条件。

## 能力档位

| 能力 | 最多比较方案 | 前瞻预算档位 | 协作 | 保存备选数 | 可见响应风险项 |
| ---- | -----------: | -----------: | ---: | ---------: | -------------: |
| 新手 |            2 |            1 |    0 |          0 |              0 |
| 普通 |            3 |            2 |    1 |          0 |              0 |
| 熟练 |            4 |            3 |    2 |          1 |              0 |
| 优秀 |            6 |            4 |    3 |          2 |              1 |
| 大师 |            8 |            6 |    4 |          3 |              3 |

`horizon` 控制 HTN 分解搜索预算，默认预算为 `32 + 32 × horizon`，不再截断必要任务。它不等同于敌军搜索树的层数。高档增加比较、评分因素、组织与备选，不修改单位数值，不保证所有地图胜率单调。

## 十四维风格

全部是 0–100 整数，50 为中性：侧翼、火力、预备队投入、任务专注、集中、坚守、佯攻、进取、风险容忍、兵力保全、机动、侦察、耐心、自主。

风格对通过条件检查的方案和动作加分，不能越过任务依赖、宿主合法性和单位归属。没有对应机制时，该项偏好可能不产生效果。

完整扩展接口、缺失机制处理和宿主异步执行约定见 [模块化任务规划](modular-tactics.md)。
